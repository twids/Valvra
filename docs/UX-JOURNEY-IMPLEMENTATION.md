Every batch retains fresh server authorization, stable identity submission, text-only rendering, CSRF, secret clearing, encrypted history and audit acknowledgement. Search uses already-authorized metadata only. Presets must not silently add permissions; audit presentation must preserve incomplete and invalid-signature records.

## Combined verification and limits

All seven journey findings have implemented changes. The combined backend suite passed 272 tests, with two external-provider tests skipped locally; 46 Node checks and eight audited import workflows passed. The full browser run passed 102 of 103 tests. Its sole failure was an existing revoke test assuming only one grant: the new reader/editor fixtures added two grants. The test now selects the intended recipient's row explicitly, and all 11 joint persona/permissions workflows passed after correction. Required CI runs the full browser suite and both database providers on the final pushed commit.

Persona coverage includes reader/editor use at 390 px, no content reads for an access administrator without content permissions, and operational-only navigation for a system administrator. Astra reviewed the complete implementation and test contracts without new blockers. Its independent live walkthrough was unavailable because CUA exposed no browsers; this is not manual UX or screen-reader acceptance. Real IIS/AD/SSO, production data volumes/import, certificate rotation and recovery remain outside this synthetic verification.

The resource filter searches already-authorized account titles and product names in memory; cross-resource title search and a new caller-only access-expiry endpoint were conditional future ideas in the review, not required for these changes. Capability guidance uses current server-provided permissions and never exposes the manager grant list to ordinary users. Import Back retains active in-memory data; focus loss clears source secrets, column mappings and source-path overrides, retaining only destination IDs and user-entered destination configuration for explicit file reselection.
