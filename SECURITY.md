# Security policy

Valvra stores organizational credentials. Security fixes take priority over feature work.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** / private vulnerability reporting for this repository when enabled. Do not post passwords, connection strings, private keys, database dumps or exploit details in public issues. If private reporting is unavailable, open an issue requesting a private contact without disclosing the vulnerability.

Include affected versions, reproduction steps using synthetic credentials, security impact and suggested remediation. Do not test against organizations or systems without their authorization.

## Supported versions

The project is currently pre-release. There is no production support commitment yet. Security fixes target the current main branch; tagged supported releases and their maintenance periods will be documented before a stable release.

## Disclosure

Maintainers coordinate remediation and public disclosure with the reporter. A security review and environment-specific verification are required before production adoption. No cryptographic or penetration-test certification is claimed.
